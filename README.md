# OpenLuxe Developer Tools

Free, open-source setups that make Claude Code and your terminal better. Each kit installs with one command, or with a prompt you paste into Claude Code.

Browse them, with install commands and Claude Code prompts, at **https://openluxe.co/developers/tools**.

| Kit | What it does | Platform |
|---|---|---|
| [Kokoro Voice for Claude Code](kokoro-voice/) | Claude Code replies and plans read aloud by an offline voice, with global hotkeys and an iTerm2 right-click menu. | macOS, Windows (beta) |

## Suggest or contribute a kit

Open an issue with what the setup does and why it helps. A kit is a folder with its scripts, an `install.sh` that is safe to re-run, an `uninstall.sh`, and a README.

## Support

The kits are free. If one saves you time, you can leave a one-time tip on its page at openluxe.co. It's a tip to OpenLuxe, not a charitable donation.
